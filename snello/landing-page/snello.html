Behind the interface

Simple on the surface.
Considered underneath.

A native Android app built with Kotlin, Jetpack Compose, and Material 3. Immutable MVI state keeps the interface predictable, while a persistent WorkManager queue handles batch processing. Four photo engines and two video engines provide control over how media is compressed.
